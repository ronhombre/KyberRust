# KyberRust

A Rust port of [KyberKotlin]([KyberKotlin](https://github.com/ronhombre/KyberKotlin)) utilizing
[neo-rust-gradle-plugin]([neo-rust-gradle-plugin](https://github.com/ronhombre/neo-rust-gradle-plugin)). This is a proof
of concept project for building Rust Gradle projects using this plugin.

This is a FEATURE-COMPLETE rewrite of KyberKotlin. This depends on
[KeccakRust]([https://github.com/ronhombre/KeccakRust](https://github.com/ronhombre/KeccakRust)) (and the
[rand](https://crates.io/crates/rand) crate when `std` is enabled).

> [!NOTE]
> All code in this project is directly ported from [KyberKotlin](https://github.com/ronhombre/KyberKotlin). It is close
> to a 1:1 port, more than I expected. I suppose all of the optimizations I have done easily translate to Rust.

## Features
* Stack Allocation ONLY (No need for a heap allocator)
* Zero-cost Abstractions (Parameters are defined at compile-time)
* no_std crate support (For embedded systems)

### Standard FIPS 203
* ML-KEM-512 (Key Generation, Encapsulation, Decapsulation)
* ML-KEM-768 (Key Generation, Encapsulation, Decapsulation)
* ML-KEM-1024 (Key Generation, Encapsulation, Decapsulation)

### NRGP (neo-rust-gradle-plugin)
This is a copy of the generated `Cargo.toml` by my plugin given the current `build.gradle.kts`.
```toml
# THIS FILE IS AUTO-GENERATED by neo-rust-gradle-plugin
# MODIFY YOUR build.gradle.kts/build.gradle FILE INSTEAD!
# CHANGES HERE WILL BE LOST!!!
[package]
name = "kyberrust"
version = "0.0.1"
authors = ["Ron Lauren Hombre <ronlauren@hombre.asia>"]
edition = "2024"
autolib = false
autobins = false
autoexamples = false
autotests = false
autobenches = false

[profile.dev]
panic = "abort"

[profile.release]
panic = "abort"

[features]
default = ["standalone"]
standalone = []
std = ["rand/std_rng", "rand/sys_rng"]
ffi = []
executable = ["dep:hex", "std"]

[dependencies]
zeroize = { version = "1.8.2", features = ["zeroize_derive"], default-features = false }
hex = { version = "0.4.3", optional = true }
rand = { version = "0.10.3", default-features = false }
keccakrust = { version = "0.0.7", path = "../keccakrust/build", features = ["standalone"] }

[dev-dependencies]
hex = { version = "0.4.3" }
criterion = { version = "0.8.2" }

[lib]
name = "kyberrust"
path = "../src/library/rust/lib.rs"
crate-type = ["rlib"]

[[bin]]
name = "kyberrust"
path = "../src/main/rust/main.rs"

```

### Sidenote

In the future, this will be the API backend for KyberKotlin for the Kotlin/Native targets.

Furthermore, this Rust rewrite should net a few improvements in KyberKotlin. Writing the Rust code by hand made me
realize a few things that I didn't realize before.
